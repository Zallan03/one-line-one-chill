## The entry

One sentence of horror. The scare is in what is withheld: a diary the writer
never kept, in their own handwriting, describing a day not yet lived — and it
ends tomorrow.

> I found my handwriting in a diary I never kept, describing a day I have not lived yet, and it ends tomorrow.

## Run

`main.ts` writes the single line to `/output/entry.txt` (108 characters, gate 1–200).

```sh
node main.ts
```
